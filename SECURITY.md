# Security Policy

## Scope

The security policy covers vulnerabilities in VoidQL and its published packages. Please do not disclose an unpatched issue publicly.

## Reporting a Vulnerability

If you have a security issue to report, email [voidql.team@gmail.com](mailto:voidql.team@gmail.com). Please include:

- A concise description of the issue and its potential impact
- The affected version, component, and configuration
- Reproduction steps or a proof of concept, if available
- Any suggested mitigation

Please allow the maintainers time to investigate and prepare a fix before sharing details publicly.
